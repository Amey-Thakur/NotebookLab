Everything you need to think deeply with your documents.

  • Chat Ask questions. Answers cite the exact page, paragraph, and source file.
  • Write Markdown editor with [[wiki-links]] and auto-save. Notes link to each other.
  • Search Full-text search across everything. BM25 ranking. Milliseconds.
  • Think AI mind maps. Socratic questions. Connections you didn't see.
  • Listen Turn documents into a two-speaker podcast conversation.
  • Own Local models. No API keys. No accounts. No internet required.

How it works

  1. Install

    Download one file. Double-click. No Docker, no terminal, no setup.

  2. Import

    Drop in PDFs, text files, Markdown. Indexed automatically.

  3. Think

    Chat, search, mind maps, transforms. Everything local.
